# GenAI Contract Analysis Platform

Hey there!

Here is how to run this project:

## Setup Instructions

### Step 1
Clone this repo into your favourite IDE:
```bash
https://github.com/cartonleg/GenAI-contract-analysis-platform.git
```

### Step 2
Run the following command:
```bash
cp .env.example .env
```
This should change the name of the `.env.example` file to `.env`

### Step 3
Edit values in `.env` to your liking (don't mess with the ones already filled for your own good, trust me I'm too lazy to explain why your db url might not work)

### Step 4
Run the following command:
```bash
docker-compose up
```

### Step 5
There is no step 5!!! Enjoy!!!
